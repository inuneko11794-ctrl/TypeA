※配当未入力レースは配当率の計算対象外。検証側の件数が少ないパターンは「検証データ不足」と表示します。相関は予測の保証ではありません。

CSV × LIVE JSON MARK COMPARISON // 変換印の比較

⑳・●・▲・✖・☆・★に変換したライン内の印並びを、過去CSVと直近JSONで比較します。無印という共通ラベルにはまとめません。

CSV分析を実行すると比較します。

集計対象はライン先頭車番のペアです。提示された組み合わせ条件に従い、1－2と1－3は対象外。平均配当の算出には選択した配当が入力済みのレースだけを使用し、各組み合わせの出現数も併記します。奇数・偶数の分析は行いません。

LOW PAYOUT HEAD PAIR LAB // ライン先頭ペア・1万円以下分析

UNDER THRESHOLD RATE

ライン①〜④の位置を区別して、各ライン先頭車番の組み合わせを総当たりします。たとえば①×②なら「①の先頭1番－②の先頭2番」と「①の先頭2番－②の先頭1番」は別集計です。3連単配当が基準以下になる割合を比較します。

各位置ペアごとに、車番組み合わせの3連単中央値で上位3・下位3を表示します。
分析CSVを読み込み、総当たり分析を実行してください。
中央値分析を実行すると、各ライン位置ペアの高低配当中央値上位・下位3が表示されます。

CSV × LIVE JSON COMPARISON // 過去CSVと直近収集データの比較

事前登録したライン①〜④の先頭車番と、結果入力後の3連単配当を同じ条件で比較します。古いJSONでライン情報がないレースは比較対象外です。

CSV分析と直近JSONデータの両方を用意して分析を実行してください。

※ラインはCSVの記載順を①②③④として扱います。単騎ラインは除外。配当未入力・0円は割合の分母から除外します。各位置ペアごとに全車番の組み合わせを調べ、最低出現数未満も「該当数」としては集計しますがランキングには表示しません。

PER-LINE CAR COMBINATION LAB // 各ライン内の車番組み合わせ分析

POSITION-SPECIFIC

ライン①・②・③・④それぞれについて、そのライン内の先頭2車の車番組み合わせ（例: 1－2, 4－7 など）ごとの平均・中央値を集計します。同じ組み合わせがライン位置によって配当傾向が変わるかを比較できます。

CSVを読み込み、分析を実行してください。各ライン位置ごとに中央値/平均の上位3・下位3と、位置間比較を表示します。

LINE POSITION MATRIX ①②③④ // ライン先頭・全並びパターン

ORDERED LINE PATTERN

単騎を除いた後のライン①②③④について、先頭車番の並びとライン全体の並びを別々に集計します。①1・②4・③7と、①4・②1・③7は別パターンです。平均だけでなく中央値、高配当率、低配当率も比較します。

CSVを読み込んで分析を実行してください。ライン先頭の組み合わせと、後ろの車番まで含めた全並びをそれぞれ調べます。

※単騎はライン数・位置番号・パターンのすべてから除外。2車以上のラインだけをCSV記載順に①②③④へ割り当てます。配当0円・未入力は率の分母に含めません。最低出現数未満のパターンは参考表示のみです。
